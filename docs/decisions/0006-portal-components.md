# ADR 0006 · 门户采用 shadcn/ui 源码组件

日期 2026-11-20。适用范围是 M12 门户的组件与样式，由[迁移计划](../plans/p1-ux-shadcn-migration.md)与[任务详情验收](../reviews/p1-ux-shadcn-migration.md)记录。

## 决定

采用 shadcn/ui 的 Base UI 源码组件。只纳入已使用的组件和样式，保留固定的上游来源及 MIT 许可，局部组件随业务代码审查。Base UI 提供对话框焦点管理、模态行为和 nonce 支持，Tailwind 由 Vite 预编译。项目色板放在静态 CSS，供页面与 body 下的浮层共享，继续用系统字体。

AntD 适合快速交付初期的表单、表格和基础国际化。任务详情需要围绕执行状态、事件证据和人工确认调整结构，改用可组合的本地组件后可以直接维护语义和布局。真实任务、键盘、权限和 CSP 检查通过后迁移其他页面，再移除 AntD。

现有表单使用原生控件和共享 Zod 契约。稳定的字段 ID 关联提示与双语错误，错误状态保存消息键。现有表格用原生表头和滚动容器，复杂筛选或虚拟化等需求出现时再按实际用例选型。GSAP 继续独立负责任务状态、事件序号和证据展开的局部反馈。

## 维护与边界

Base UI 等依赖升级仍需锁定版本和回归。已调整的源码组件由项目维护，上游修复通过固定版本对比后逐项合入。升级至少检查真实任务确认、焦点、双语、CSP 与报告隐私。组件处理显示与用户输入，真实权限、审批和执行资格由蓝图规定的控制面工作流校验。
