# ADR 0005：文本预审与正式源码审计分开

- 日期：2026-11-19；状态：P1-E 采用。

预审接收客户端有限文本作为数据，在受限固定匹配器中给出观察与疑似线索，不获取/执行片段，不在宿主启动扫描器，不调用模型。Runner 未通过隔离验收时，正式仓库获取/源码扫描/构建仍关闭。无命中不等于已验证安全，预审不能给予发布资格。

内置规则/Skill 由软件版本提供，只读并带来源、类型、版本和内容指纹。Skill 与指导材料本身不执行检查；P4 再实现导入、验证、审核、发布/回滚和沉淀。P2-A 再增加动态工具选择、上下文和模型预算等自主 Agent Harness；本批固定匹配不是该 Agent 的替代。

预审为同步、有界处理，保存正式 report ID、语义输入指纹、受信任规则快照和不含源码的机器结果，供 API/MCP/门户重查。请求原文、原始路径、匹配摘录不持久化或记录日志；显示语言在查询时应用。同主体/项目/UUID 键幂等，创建需项目写权限，查询按当前项目权限。

有限 diff 只解释单文件文本 hunk 计数与新增行，不应用补丁、验证文件存在或构造修复快照。来源标记为客户端提供，不能冒充平台固定源码版本或执行证据。预算与执行权等原有治理约束不变，也不占用一个业务工作流执行 slot 来等待文本请求。
