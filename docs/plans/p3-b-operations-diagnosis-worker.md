# P3-B3c2 · 正式诊断 Worker 与结算

接续 [诊断检查点 #78](https://github.com/MaLaNg116/itervane/pull/78)。一个正式诊断任务使用同一个冻结输入、模型指纹、已发布目标和执行槽。 [正式任务计划](p3-b-formal-operations.md)

| 工作 | 验收 |
| --- | --- |
| 诊断 Worker | 仅匹配冻结配置的 Worker 领取诊断。模型读取主机提供的投影。状态、日志和指标使用 Whiskers MCP 只读身份，发布历史从已核验账本读取。读前、读后及回执入库均核对预留操作和当前执行权。 |
| 证据化结算 | 对照已发布检查点和不可变读取记录重建结论，在同一事务保存诊断、容器状态、成功事件和释放执行槽。取消、撤权、换绑及事务失败不留下成功记录。 |
| 验证 | 用 PostgreSQL 和固定 Whiskers 协议响应验证真实 Worker、受限工具集合、事件回滚，以及接管后重放最终结论。保持原有观察任务和入口兼容。 |

B3d 接入安装配置、门户和外部 MCP，按同一任务验收托管容器与原生 Whiskers。重启、版本恢复或关联代码修复由 P3-C 处理。
