# P3-C1b2 · 双语处置提案与审批入口

接续 [人工决策 #84](https://github.com/MaLaNg116/itervane/pull/84)。使用同一领域服务查询与请求提案，通过门户记录人工决策。 [P3-C 分批计划](p3-c-operations-proposals.md)

| 工作 | 验收 |
| --- | --- |
| 投影 | 返回已核对的处置类型、当前发布、恢复版本、有效期和决策记录。查询遵循当前项目授权，过期、目标变化和授权失效有明确状态。 |
| 双向入口 | HTTP 和 MCP 共用查询与请求提案。HTTP 决策沿用现有门户身份检查。请求拼接的目标和审批参数不能扩大范围。 |
| 门户 | 中英文展示同一决策与目标，复用确认弹窗、减少动效与当前版本校验。验证普通查看者、提交者和所有者的交互。 |

C2 接入批准后的派发、真实下游确认和恢复验证。当前投影记录提案及人类决策。
