# P4-A2 · 设计 Skill 审核与版本发布

接续 [#135](https://github.com/MaLaNg116/itervane/pull/135)。所有者在门户身份下核对已存版本，留下人工审核回执，并通过独立命令发布、回滚或撤销。 [P4 总计划](p4-rule-learning.md)

1. 人工审核按包、版本、正文摘要与所有者授权绑定。审核覆盖来源与许可证、适用范围与指导、随附材料。全项确认得到通过回执，待改回执给出修改意见。每个版本与授权代次最多一份决定。同内容可重放，修改内容进入新版本。
2. 发布与回滚按包串行记录单调序号，检查操作者、目标版本、目前序号与通过的审核摘要。回滚只能选择历史上正式激活过的版本，且核对当前授权下的审核。撤销绑定当前版本和序号。重放返回原操作，并显示目前状态。当前版本从最后一笔记录推导。
3. 版本和发布历史有双语 HTTP 读面。草稿、审核结果和当前发布资格分别投影。多次操作不能覆盖历史回执。用户提交的设计资源继续作为文本，后续 Agent 引用与任务版本绑定在 P4-D 验证。
4. 使用 PostgreSQL 和签名 OIDC 测试身份验证错误身份、过期版本或授权、并发、回滚到已发布版本、撤销、历史匹配与直接数据库改写拒绝。该阶段的人工设计审核与后续代码规则的隔离验证分别保留回执。
