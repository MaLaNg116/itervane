# P4-C2b · 一次性虚拟机的规则样例回执

接续 [#141](https://github.com/MaLaNg116/itervane/pull/141)。把固定候选与样例送入现有可信 KVM Runner，沿用专用账号、Unix socket、租约心跳、静态映像和销毁核对。 [P4-C 总计划](p4-candidate-validation.md)

1. Worker 对候选、三份样例、配置、检查器和映像计算固定摘要。命令只携带该组样例材料，控制器先通过同一对端 UID、工作区、映像和心跳校验，再将正文交给一次性域。
2. 来宾通道只接受定长标识和有大小上限的 JSON。扫描账号以只读方式访问已封装的 Semgrep 工具和样例命令，现有网络、设备和权限约束覆盖实际执行。返回归一化的版本、证据摘要、覆盖与命中数。
3. Worker 独立检查回执作用域、样例绑定、全量覆盖和正反判定。孤儿域或清理未知返回待核对状态。正常的样例失败可记录为失败，供人工修订。
4. 托管 KVM 使用固定合成规则验证通过及误报的两个独立域，再核对错误映像和取消授权均在启动前被拒。保存 CI 回执与源代码指纹。C2c 将本次原生通道绑定到 PostgreSQL 候选验证、全局单槽和人工发布闸门。
