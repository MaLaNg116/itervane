# P3-B2 · 运维 Agent 的证据调查与结论

接续 [日志与指标证据 #74](https://github.com/MaLaNg116/itervane/pull/74)。复用 LangGraph Harness 的预算、权限核对、证据指纹和检查点。 [P3-B 计划](p3-b-operations-agent.md) · [蓝图](../blueprint-v6.md)

| 需求 | 工作与验收 |
| --- | --- |
| 运维角色和调查工具 | 独立角色只读取固定容器的状态、当前及上一条已核验发布、脱敏日志信号与一小时指标。模型按证据决定顺序和可选调查，重复调用不增加观察。工具参数只有证据类别。容器与安装绑定、发布身份和请求摘要由宿主注入并核对。 |
| 可核验结论 | 宿主根据回执生成事实引用，模型提供有限类别的假设和建议。完成前需容器状态及发布证据。日志与使用率可作为假设线索，建议重启需容器已退出或失效，建议恢复需可核对的前一已发布版本及变化与异常的观察。建议由后续审批流程处理。双语由平台模板表达。 |
| 恢复与评测 | 区分运行中和已退出样例，两条路径分别按证据选择指标或日志。验证错误引用、跨容器回执、重复调查、权限撤销、过程暂停恢复和最终检查点再验证。保留旧检查点与交付角色的协议。 |

模型能观察已归一化的事实、采集时间和证据引用。服务地址、密钥和原始日志留在适配器边界。B3 使用与当前租约绑定的 PostgreSQL 证据读取和持久化接口，接到真实运维任务与门户。
