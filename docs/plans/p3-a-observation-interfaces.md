# P3-A2-C · 门户和 MCP 的只读诊断入口

接续持久化观察与原生发布容器验收。使用同一接收服务与回执读模型，沿用项目授权和短事务。 [持久化执行](p3-a-observation-execution.md) · [原生验收](p3-a-published-observation-native.md)

| 批次 | 实现与验收 |
| --- | --- |
| C1 授权回执 | 按当前项目读取诊断任务状态及固定的历史观察。由任务角色、请求摘要、发布和回执共同确定真实性。门户与 MCP 共享中英文状态和原因，返回字段经过投影。真库验证两种语言、撤权、旧观察保留及无关任务。 |
| C2 对外接收与查询 | 安装配置显式打开接收，绑定可用环境与已登记指纹。HTTP 和 MCP 复用现有身份、写入范围、领域幂等和同一结果。验证默认关闭、旧密钥及登记、请求重放、部署占用、浏览权限与服务端脱敏。 |
| C3 门户接续 | 只在有效安装范围提交诊断，显示进度、观察时间、容器状态及失败原因。使用现有导航、样式、GSAP 和无动效偏好。真实浏览器验证项目切换、权限、CSP 和双语界面。 |

观察结果表示特定发布容器在观察时刻的运行状态。健康与故障因果分析由后续诊断角色补充。下游连接地址、密钥、原始工具正文与服务器身份保持于 Worker 和受控记录内。
