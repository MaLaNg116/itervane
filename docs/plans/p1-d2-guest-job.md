# P1-D2-B 一次性 VM 作业通道与停止验收

- 基线为 PR #15 合入后的 `97ea680`。参考 [v6 蓝图](../blueprint-v6.md#15-安全隔离与恢复边界)、[分阶段实施计划](../implementation-plan-v2-ts-postgresql.md#p1-建立可授权可恢复的真实任务底座)、[P1-D 总体计划](p1-d-isolated-source-inspection.md)和 [D2-A 原生证据](../reviews/p1-d2-runner-native.md)。
- 目标是在真实 KVM 上完成一项有界客体作业，并在客体确认已收到数据后实测取消、超时和清理。复用现有 Linux 宿主与可信镜像制作流程。

## 实施顺序

| 单元 | 工作 | 验收 |
| --- | --- | --- |
| B1 | 固定长度版本帧。请求绑定本次 VM 随机标识、输入长度与 SHA-256。客体先读取首块并回执首块摘要，再流式验证完整输入。 | 只识别固定作业，拒绝错误版本、超长输入、截断数据和错误摘要。回执不带文件路径、源码或日志。 |
| B2 | 暂停状态下检查额外的命名 virtio-serial 通道。宿主通过 libvirt 打开该通道；客体以专用低权限身份运行固定服务。 | 核对通道数量、名称和传输类型。宿主发送内部生成的字节。客体无需网络设备、共享文件系统、QGA 执行权限或仓库凭证。 |
| B3 | 贯通中英文回执及原生验收。保留整个生命周期时限，为客体通道增加单独的有界时限。 | 完整多块输入的回执与宿主摘要一致；改动末尾字节被拒绝；客体确认首块后，宿主分别发送真实 SIGTERM 或等待作业时限。每轮核对实际域已消失、磁盘和 journal 已移除。 |
| B4 | 复查差异，保留固定版本的导读和实测证据。 | Python 协议和宿主回归、TypeScript 回执校验和现有 CI 均通过，原生验收识别通过、拒绝、取消、超时及未确认清理。 |

## 作业与执行资格

本批客体作业是固定的输入摘要核验。验收驱动在维护者环境内生成输入，取消与超时场景保留剩余字节，确保收到首块回执后仍有工作未完成。宿主只对本轮域开启一次通道；无有效回执、时限到达或取消时进入既有销毁与独立核对流程。清理证据不明确时保留运行记录，下一轮继续阻断。

D2 总体验收还包含宿主与跨任务隔离、资源和进程限制的完整证据。D3 在合格控制器上接入固定 Git commit、受保护的扫描器和带执行权的产物发布。本批原生证据存放在验证路径，正式 Worker、门户、MCP 和发布继续按 v6 的授权、隔离和审批条件执行。

参考 [libvirt 命名通道](https://libvirt.org/formatdomain.html#channel)、[libvirt 打开通道 API](https://libvirt.org/html/libvirt-libvirt-domain.html#virDomainOpenChannel)和 [libvirt 非阻塞流](https://libvirt.org/html/libvirt-libvirt-stream.html#virStreamRecv)。
