# 仓库首页刷新计划

以 v0.1.0 的正式发布为基线，让首次访问仓库的读者能判断 Itervane 的用途、适用范围和自托管条件。 [v6 蓝图](../blueprint-v6.md) · [发布验收](../release-acceptance.md)

## 实施

1. 对照十个 Agent、自动化、自托管和隔离基础设施项目的 README。记录它们的首屏信息、上手路径、界面展示和文档入口。
2. 改写英文首页并提供对应简体中文版。将产品定位、发布入口和实际门户预览放在首屏，接着介绍三条工作流、参考安装、验证记录和维护者文档。
3. 使用正式发布源码的门户构建和可信浏览器夹具获取截图。说明示例数据来源，并检查画面中的项目、任务及环境信息。
4. 保留本批 Review Guide 和调研来源。按正式源码包清单核对安装命令、公开下载链接、授权边界及双语内容。

## 验收

- 读者能从首页找到版本下载、参考控制面安装和完整部署所需的 Runner、发布与运维配置。
- 两版首页都准确描述三条闭环、双向 MCP、人工审批、一次性 VM 和 v0.1 适用范围。
- 预览可读，双语切换、文档锚点、图片和发布链接均可用。运行次数、数据库测试、备份与模型口径引用同版回执。
