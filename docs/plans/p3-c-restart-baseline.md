# P3-C2c3b1 · 冻结重启前的同一容器

恢复核验器已经可以观察同一容器的时间推进与受保护健康。本批把发送前的停止快照与 Whiskers 请求固定在同一 PostgreSQL 事务，供后续独立结算复用。 [恢复核验计划](p3-c-restart-recovery-evidence.md)

- 首次发送前，当前租约依据冻结发布解析实际 Komodo 映射、镜像、版本和入口，读取停止容器。每次读回前后检查平台授权。目标与策略全部匹配后，停止锚点和其摘要与首次意图一并持久化。
- 人工续发之前再次读取同一容器。快照变化或缺失时停止发送并进入现有只读核对。历史记录保留原样，新的续发必须具备停止锚点。
- PostgreSQL 校验快照结构和目标绑定，并保护既有锚点免于更新。真库验证同一意图、快照不匹配阻断、失败事务回滚和续发接管。
- 后续结算阶段使用历史发布与固定安装读取原操作效果，完成确认的恢复与原生许可核对，再以独立租约提交结果。正式写入口按 C2c3c 的安装与同一应用验收开放。
