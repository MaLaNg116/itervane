# P5-C1 · 核对三次参考运行的独立性

在各自的托管 KVM 作业通过后，读取同一次工作流上传的三份参考验收报告，对照当前检出的 Git 树与场景。冻结三个开发和三个运维回执的独立性证据。 [参考开发验收](p5-reference-release.md) · [参考运维验收](p5-reference-operations.md) · [Runbook 复用 #167](https://github.com/MaLaNg116/itervane/pull/167)

1. 汇总作业只读取本次工作流的三个指定产物。逐个匹配场景和源码树，保留原作业的 KVM、身份、业务与恢复判据。
2. 检查不同项目、任务、运行、审批和恢复事件。初检与复验域合计须有六个独立 UUID，各运维回执须绑定同次发布。
3. 保留汇总回执，供维护者在最终发布时定位对应检查。其余发布出口仍按原计划审核，包含参考环境代码规则复用、故障并发、恢复及发布材料。
