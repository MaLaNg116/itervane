# P3-A2-C3 · 已发布任务的双语只读观察入口

接续 [HTTP 与 MCP 入口 #72](https://github.com/MaLaNg116/itervane/pull/72) 和 [原生已发布容器验收 #71](https://github.com/MaLaNg116/itervane/pull/71)，以 P3 的真实运维和门户验收为准。 [阶段计划](../implementation-plan-v2-ts-postgresql.md) · [运行闸门](../decisions/0001-development-and-runtime-gates.md)

| 需求 | 实现与验收 |
| --- | --- |
| 发布详情的可用入口 | 复用正式发布与登记核验，按当前项目写权限查询同一发布任务的启动选项。后端关闭、目标变更、现有发布待核对时收回入口。提交携带页面上看到的发布操作 ID，持久化接收事务内复核。已接收请求按原键重放。真实 PostgreSQL 覆盖作用域、发布变化、换绑与撤权。 |
| 诊断任务的结果 | 用已持久化的当前 run 角色识别运维任务。在现有任务详情展示状态、事件、原因、容器状态和观察时间，保留回执摘要及发布操作关联。显示语言独立于提交语言。 |
| 门户行为 | 用户在已核验的发布详情启动观察。请求失败后重试复用原键，离开页面后原请求的晚到响应不接管当前导航。只读用户可看有权访问的诊断历史。沿用现有 shadcn/ui 组件、GSAP 状态反馈、无动效偏好及 CSP。用真实 Chromium、Keycloak 与 PostgreSQL 验证中英文、导航、权限收回和同源行为。 |

本批观察发布容器在特定时刻的状态。证据推理、健康检查、获批处置与关联修复接续于 P3 后续批次。
