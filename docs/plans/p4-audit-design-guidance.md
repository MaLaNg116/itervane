# P4-D5 · 正式审计引用已审核的设计 Skill

项目维护者可以上传并审核发布通用设计 Skill。本批让内置审计 Agent 读取任务接收时固定的适用设计指导，保留包版本、审核和使用回执。 [规则生命周期计划](p4-rule-learning.md) · [#158](https://github.com/MaLaNg116/itervane/pull/158)

1. 复用版本、激活、审核和项目作用域解析。将已审核的本地化摘要与同语言的有界 `SKILL.md` 摘录作为审计输入，绑定任务规则快照。附件仍由规则库按授权提供，Worker 不执行上传内容。
2. 让现有只读规则工具提供指导，并在 Agent 证据与双语报告记录包键、版本、审核和快照摘要。模型可以引用指导提请人工核对。正式扫描覆盖、工具白名单和发布闸门继续由控制面判定。
3. 用 PostgreSQL 验证读取已发布且适用的版本、回滚后的历史读取和不可用引用。用常见表单反馈设计规范示范真实任务的读取与留痕，检查指导内容无法改变执行工具和扫描完成条件。
