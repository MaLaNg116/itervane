# P5-C4 · 参考验收的质量与资源报告

以源码发布包批次为比较基线，为同次托管参考验收保留可核对的质量、耗时、模型使用量和存储数据。 [P5 发布验收](../implementation-plan-v2-ts-postgresql.md#p5-验证可靠性并形成可复现的开源交付) · [前置 #172](https://github.com/MaLaNg116/itervane/pull/172)

1. 在三个干净参考执行中以单调时钟记录正式任务受理至发布读回、合成容器停止至健康事件独立恢复的耗时。保存故障、扫描修复、授权、读回和任务槽判据，持续使用正式入口、固定镜像和隔离 Runner。
2. 读取审计、修复、复验与诊断的持久化模型使用量，以及核验的 OCI 档案字节数、参考 PostgreSQL 数据库占用。汇总只接收同一代码树的三份结果，同时核对独立任务、运行、VM 与审批记录。
3. 记录报告口径。托管模型使用固定协议响应，单独记录本机授权模型在相同合成用例上的实测和确定性对照。服务商账单、生产人审时间和外推估算需有独立依据。
4. 最终发布按实际运行回执补齐可追溯的故障和并发覆盖表。只统计独立核对完成的场景，缺失与失败保留实际状态。
