# P3-C3-D · 健康事件读面、确认与停止诊断

接续 [#129](https://github.com/MaLaNg116/itervane/pull/129) 的原生联验。围绕控制面登记的运维环境，让维护者理解事件、找到关联任务并操作正式处置入口。接续既有项目权限、全局执行槽和门户审批。 [阶段计划](p3-c-operations-incidents.md) · [蓝图 v6](../blueprint-v6.md)

| 批次 | 内容 | 验收 |
| --- | --- | --- |
| C3-D1 授权读面 | 在登记环境与已授权任务上查询最新健康结果、事件与关闭或停止原因。关联采样、诊断与关联修复采用数据库中已有的不可变依据。投影仅包含供用户查阅和定位任务的字段，中英文通过同一契约输出。 | 真库核对两种语言、历史事件、诊断与修复引用、未知或交替版本、跨项目拒绝及不暴露容器内部坐标。 |
| C3-D2 确认与停止、外部 MCP | 复用 C3-C 的正式提案与确认服务。Portal 身份确认关联修复，按固定版本和指纹校验。停止从事件入口持久化并阻止后续自动诊断，选定任务的取消沿用现有任务控制；外部 MCP 提供相同授权读面与相应审批入口。 | 真库与 MCP 测试核对相同读面、作用域、停止并发和重放，拒绝过期或越权请求，保留诊断或审批前后的状态与证据。 |
| C3-D3 门户和原生验收 | 在现有项目环境、运维任务和关联任务界面呈现状态与下一步。保持中英文、shadcn/ui、GSAP 与减少动效。用受保护应用串起触发、停止和恢复，以及另一个合格事件的关联修复。 | 浏览器验证双语导航、确认和拒绝反馈、减动效及状态重载。托管原生联验记录真实入口、持久化停止、已部署版本关联与外部 MCP 读取。 |

查询保留原版本的历史依据，按登记环境和当前项目权限过滤。详情提供事件、发布及可导航任务编号，采样和诊断摘要保留稳定引用。读取路径复用控制面访问服务，写入路径让已登记的用户操作继续经过既有审批与授权核对。预算达到上限或用户停止时，保留健康采样和历史记录。
