# P4-D2b1 · 原生 Runner 固定规则扫描

接续 [#147](https://github.com/MaLaNg116/itervane/pull/147)和[扫描计划](p4-published-source-scan.md)。本批把规则扫描接入正式来源检查的同一份授权、固定提交和一次性虚拟机回执。

1. 扫描请求携带固定规则输入的长度、摘要与当前镜像摘要。Runner 在工作区、镜像、来源及租约核对通过后接收有界命令。固定规则命令与远端来源请求分别绑定，由一次性虚拟机按现有网络闸门取得源码。
2. 固定源码进入只读挂载后，从控制面固定的规则包与样例回执重建规则。隔离服务在同一快照上保留 Gitleaks、Trivy 与规则扫描结果。代码规则回执携带完整文件清单，调用方重算快照摘要、覆盖清单及规范化证据，检查域清理、命令和镜像绑定。未启用规则的请求沿用既有回执结构和大小。
3. 增加协议兼容、篡改、授权和证据校验回归。用托管 KVM 连接后，补充正式任务按固定快照选取版本、Agent 审计读取、复验与第二个登记项目的持久化验收。

后续批次从数据库读已审核规则，将扫描和复验绑定到正式工作流及发布门槛。本批授权来自原有 Runner 租约，支持在运行通道上验证可选的规则输入。
