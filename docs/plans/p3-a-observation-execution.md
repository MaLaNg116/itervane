# P3-A2-B2-B · 持租约读取并记录运行事实

接续诊断接收及固定绑定。Worker 安装配置包含环境、Whiskers 登记指纹及单独的 Read 密钥。由本机安装范围与当前登记共同决定唯一 MCP 端点和容器。 [诊断任务计划](p3-a-durable-observation.md)

1. 复用业务队列和全局执行槽。仅匹配环境的 Worker 领取 `operations` run。未安装或环境不同的 Worker 将唤醒推迟给匹配安装。开始读取时复核已授予权限、发布占用、当前已核验发布和登记指纹，消耗一次持久化观察预算。后继执行者可以在剩余预算内重新读取。
2. 只有受控适配器可以调用 Whiskers。每次实际下游调用前及收到结果时重新核验租约、授权和目标。下游调用发生在数据库事务外。取消、变更、超时和结果完整性问题分别留下受限原因。
3. 保存回执时再次取得当前执行权。回执、完成事件和任务结果在同一事务提交。回执固定任务、run、执行代次、发布操作及绑定摘要。独立数据库触发器校验执行代次并冻结已发布回执。

专项验证使用真实 PostgreSQL，配合受控的协议回执检验结果一致性、并行 Worker、取消、变更和断开后的重领。B2-C 将相同 Worker 接到真实 Whiskers 与本轮 Komodo 发布容器。业务入口随 A2-C 单独验收。
