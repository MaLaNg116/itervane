# P2-E-D3-B · 正式上线证据与原子结算

接续 [独立核验租约 #56](https://github.com/MaLaNg116/itervane/pull/56)。本批为正式部署保留可追溯的结果，供后续安装侧 Worker 和门户、MCP 共用。 [D3 分批计划](p2-e-rollout-settlement.md)

| 任务 | 实现与验收 |
| --- | --- |
| B1 结算账本 | 在当前核验尝试追加不可变结果。成功证据绑定操作、租约、冻结指纹、人工决定、代次、目标修订、原生更新和同一镜像的实际运行证据。真实 PostgreSQL 拒绝空证据、篡改绑定、过期租约、无凭据释放和部分结算。 |
| B2 只读观测 | 在一次租约内回读同一个成功的 Komodo 更新，检查实际容器与授权入口和健康响应，重新读取原生更新后结算。适配器只返回有限字段，记录失败时使用双语原因码。 |
| B3 恢复与回归 | 重复 Worker 或中断接手只保留一个结果。核验失败转人工并保留目标环境占用。派发后取消时，已发生的真实发布可入账，任务仍保留取消状态。 |

只有真实运行证据、任务事件、当前核验尝试和环境释放一起提交，正式操作才进入 `verified_formal`。允许既有操作在本人批准撤回、过期或权限撤销之后核对已经发生的结果。读取过程中继续执行每一步租约检查。凭证和完整下游响应留在服务端。

正式自托管 Worker 的配置和双语查询接入在 D3-C。D3-D 用真实 KVM、Komodo、Traefik 和 Keycloak，在同一操作中从外部 MCP 接续到上线结果。
