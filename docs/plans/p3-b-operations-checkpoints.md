# P3-B3c1 · 正式诊断检查点

接续 [冻结输入及证据预留 #77](https://github.com/MaLaNg116/itervane/pull/77)。诊断的工具计划、预算和观察结果通过 PostgreSQL 恢复。此批提供正式 Worker 启动调查所需的执行权边界。 [正式任务计划](p3-b-formal-operations.md)

| 工作 | 验收 |
| --- | --- |
| 领域指针 | 按诊断 run、冻结输入和执行代次发布检查点，使用独立的 `operations:<runId>` 线程。数据库约束角色、状态、登记、租约及步数递增。 |
| 运行时保护 | 检查点读写重新核对当前权限、目标、模型指纹及输入。恢复只读取已发布检查点和已确认的中间写入。 |
| 恢复验证 | 使用真实 PostgreSQL 验证未发布数据隔离、接管前后读写约束，以及取消、撤权和换绑。运行可信 ReAct 样例，验证新 Worker 重放已持久化的证据并能继续调查。 |
