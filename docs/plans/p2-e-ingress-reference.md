# P2-E-D2-C · 自托管受保护入口

接续 [入口验证器 #54](https://github.com/MaLaNg116/itervane/pull/54)。将本机与托管环境已通过的路径落到可自托管的应用网络，继续使用原有 Komodo、Traefik、Keycloak 和独立人工审批。 [D2 总计划](p2-e-protected-ingress.md)

| 工作 | 交付 | 验收 |
| --- | --- | --- |
| 参考接线 | 固定 Traefik 和 OAuth2 Proxy 镜像、Traefik 文件 provider、自带 TLS、应用专用身份配置。初始化命令由安装维护者运行。 | Compose 配置能检查和复现。发布目标绑定应用私网、外部入口、专用探测身份及仅管理侧可读的 Traefik API。配置及客户端密钥可分别轮转。 |
| 运行隔离 | 应用仅加入专属内部桥接网络且无宿主端口。Traefik 同时接入应用、认证和管理网络。只读转发实例从本机回环访问业务代理的管理网卡，认证服务无宿主端口映射。 | 在独立可信容器演练可达性。代理可联通应用和认证，应用侧无法直连管理网卡或认证服务，匿名访问保护成立。 |
| 发布联调 | D3 使用正式 Worker 持久化的原生更新和实际 Komodo 目标回执完成同候选核验。保留生产入口闸门与现有审批。 | 用真实获批 OCI 和受保护入口验收，回读镜像、容器与路由一致，断连或证据冲突保持待核对。 |

参考配置以单应用实例为起点。外部访问需提供真实 HTTPS 证书和域名，安装示例的监听默认为回环。独立应用网络的成员与用途在维护侧登记，Traefik 不使用 Docker socket 或应用标签。所有设备和凭证仍由维护者持有，Agent 得到有界的核验证据。
