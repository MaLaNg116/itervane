# P2-D3-D · 正式复验 Agent、返修与读面

承接 [独立复验计划](p2-d3-formal-verification.md)和[持久 OCI 制品 #32](https://github.com/MaLaNg116/itervane/pull/32)。使用同一任务代次的正式证据形成复验意见，为下一阶段的发布候选提供输入。发布资格仍由 P2-E 按当前权限、制品、环境与人工审批核验。

| 批次 | 交付 | 实测出口 |
| --- | --- | --- |
| D-A | 正式复验事实和模型可读投影 | 从已核验并持久化的同一回执派生候选、源差异、基线、镜像扫描和制品事实。缺证、实际失败和已观察到的风险可区分。 |
| D-B | 受限 ReAct 复验角色 | 沿用 LangGraph、PostgreSQL 检查点、预算和授权。角色基于事实选择观察工具，生成可查证说明及返修方向。两种不同证据驱动不同路径。 |
| D-C | 接入真实 Worker 与受控返修 | 扫描通过的原稿与已封存的修复候选均进入正式复验。无证据时暂停。返修创建新代次，绑定失败证据和预算，通过同一授权重新执行。 |
| D-D | 双语结果、任务时间线与实机闭环 | 门户及 MCP 从同一受授权数据读出复验事实和意见。健康、回归、两类修复及中断恢复在真实 PostgreSQL、模型和托管 Runner 验证。 |

正式事实来源于受保护 Runner 和已有事务。模型获得有界摘要和可引用证据，保持对工具结果的动态观察。结果绑定项目、任务、run、候选、复验 profile、Runner 证据和归档地址。正式判定独立核对目标问题退出、回归、新增问题及冻结规则。现有中英文、GSAP、工作区授权和运行闸门沿用 v6。
