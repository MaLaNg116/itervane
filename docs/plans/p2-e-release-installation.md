# P2-E-D3-C · 正式 Worker 安装与双语结果

接续 [正式结算 #57](https://github.com/MaLaNg116/itervane/pull/57)。用同一操作连接已实现的 Registry 导入、Komodo 派发和只读结算。 [D3 分批计划](p2-e-rollout-settlement.md)

| 交付 | 实现与验收 |
| --- | --- |
| C1 安装与调度 | 提供维护者启动的发布 Worker。安装配置绑定一个已登记环境与目标指纹，Runner 从现有受控通道读取固定 OCI。Registry、Komodo 和探测身份凭证仅供发布进程使用，逐步对照当前租约和目标。写入使用既有共享执行槽，核验使用独立短租约。 |
| C2 同源结果 | 从已授权任务读取其发布操作及脱敏证据，门户与只读 MCP 使用同一契约。结果含操作与原生更新标识、版本摘要、健康结论和双语失败原因。已有审批与申请入口沿用当前权限。 |
| C3 回归 | 真 PostgreSQL 下验证缺少配置、目标指纹变化、取消、撤权或重复 Worker。无效配置无法触发任何下游写入。浏览器与实际 MCP 客户端读取相同的已确认结果。 |

安装时使用登记命令返回的环境与指纹，启动前确认它们和数据库中的当前记录一致。启动后的每次写入都重新检查授权和目标版本。下游已派发或 Worker 重启时，只能接续已保存的步骤。凭证经既有本机私密配置提供，Portal/API 无需加载发布凭证。

安装进程分别轮询正式发布队列和待核验操作，共享工作流写入租约，并保留取消后的只读核对。页面复用当前发布面板、定时刷新、中英文和减少动效处理。接口保留项目授权与任务边界。

D3-D 使用本安装路径在一次性测试环境验收从外部 MCP 到实际受保护入口的完整 P2。平台公开的发布能力状态随该验收确认。
