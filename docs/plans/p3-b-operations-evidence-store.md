# P3-B3b · 正式诊断输入及证据预留

接续 [发布历史证据 #76](https://github.com/MaLaNg116/itervane/pull/76)，沿用已发布容器、项目授权代次和安装登记。 [正式任务计划](p3-b-formal-operations.md)

| 工作 | 验收 |
| --- | --- |
| 冻结输入 | 在任务接收事务内按可信安装范围固定模型指纹、诊断输入及四类读取预算。请求重放保留已接收模式。只有兼容的 Worker 可领取诊断运行。执行能力随 B3c 的 Worker 安装接续。 |
| 证据预留 | 使用运行 ID、类别和操作 ID 唯一绑定每项读取。租约锁保护预算与持久化，首次预留消耗一次类别预算。回执随当前执行代次记录。 |
| 恢复和回放 | 已记录事实按原摘要重放。失效领取允许后继 Worker 使用同一操作 ID 再试一次，旧 Worker 的结果失效。取消、登记变化、撤权和并发发布沿用原闸门。 |

使用真实 PostgreSQL 验证事务失败、重复领取、持久化预算、旧代次写入、权限变化、恢复及历史观察兼容。B3c 接入真实 Whiskers、发布证据读取和受租约保护的图检查点。
