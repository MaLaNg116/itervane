# P4-D2b2 · 正式任务持久化已发布规则检查

接续 [#148](https://github.com/MaLaNg116/itervane/pull/148)。为正式来源检查从任务固定快照读取审核过的规则，读回时复核同一份输入及授权回执。

1. 在当前任务工作区按快照引用读取激活动作、版本、审核和通过的候选验证。从保留的不可变记录重建规则，不重新选择当前版本。跨项目只允许工作区范围的规则，项目范围必须与目标一致。
2. 在现有租约事务中固定请求摘要、激活快照和引擎画像。数据库核对请求与回执绑定，重启后使用留档画像重建同一命令。已有无规则检查记录仍可查阅，固定规则待查或检查不可用时正式任务明确暂停。项目授权和宿主 Runner 闸门仍由既有入口核对。
3. 对正式审计准备可引用的已发布规则发现，记录来源、覆盖与证据摘要。门户和外部读取复用已有身份及项目授权，只输出相应的摘要和授权范围内的发现。用真实 PostgreSQL 验证旧任务、同一任务回放、跨项目、版本切换、失效执行者与检查缺失的行为。

下一批在独立复验中运行同一规则集，核对修复后结果并接发布资格，随后使用第二个登记项目做原生复用验收。
