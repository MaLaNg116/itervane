# P4-D2b2 · 正式任务持久化已发布规则检查

接续 [#148](https://github.com/MaLaNg116/itervane/pull/148)。为正式来源检查从任务固定快照读取审核过的规则，读回时复核同一份输入及授权回执。

1. 在当前任务工作区按快照引用读取激活动作、版本、审核和通过的候选验证。从保留的不可变记录重建任务提交时的规则。跨项目只允许工作区范围的规则，项目范围必须与目标一致。
2. 在现有租约事务中固定请求摘要、激活快照和引擎画像。数据库核对请求与回执绑定，重启后使用留档画像重建同一命令。已有无规则检查记录仍可查阅，固定规则待查或检查不可用时正式任务明确暂停。项目授权和宿主 Runner 闸门仍由既有入口核对。
3. 为正式审计固定规则扫描回执，并在双语任务页显示检查文件数和命中数。已授权的 API 读取使用同一摘要。用真实 PostgreSQL 验证旧任务、缺失执行资格、持久化回执、撤回后的历史重读和新任务选取。

后续批次让审计 Agent 引用规则命中，并在独立复验中运行同一规则集。复验接入后根据已验证结果判断发布资格，随后使用第二个登记项目做原生复用验收。
