# P3-C3-D2 · 事件停止、关联确认与外部 MCP

接续 [#130](https://github.com/MaLaNg116/itervane/pull/130) 的授权读面。分两批实现已登记项目中的事件操作。 [C3-D 计划](p3-c-incident-views.md)

1. 外部 MCP 复用双语环境列表和任务事件引用。工具描述、输入校验和权限沿用现有 MCP 注册方式。签名会话的读取结果与 HTTP 使用相同投影。
2. 门户所有者可停止指定事件的自动诊断。请求与事件的发布和恢复版本绑定，事件状态及执行人的授权随停用事务保存。并发重复停止返还同一记录。调度器和当前诊断的租约检查继续读取持久化停止字段。对单项任务的取消沿用现有控制入口，健康采样继续记录。
3. 后续子批接入关联修复提案的授权读取、准备和门户确认。准备从已核验诊断和登记解析范围，确认继续由正式领域服务校验指纹与固定源码，发布仍由相应独立审批执行。对外保留操作前后的证据和可追溯任务引用。

验收使用真实 PostgreSQL、签名测试身份和真实 HTTP/MCP 请求，覆盖不同语言与角色、令牌受众、错误环境和发布、并发停止、停止后的 Worker 授权，以及修复确认的重放。C3-D3 接入门户交互和受保护应用的原生停止与恢复。
