# P4-C3b · 双语规则库与审核门户

接续 [#144](https://github.com/MaLaNg116/itervane/pull/144)。沿用现有登录、项目访问控制、shadcn/ui 组件、GSAP 与减少动效。 [P4-C 计划](p4-candidate-validation.md)

1. 工作区所有者可浏览规则包版本、当前激活状态与历史。在导入界面选择 `SKILL.md`、Markdown 参考文件及 JSON 设计资料，补充来源、许可证、版本、中英文摘要和作用域。浏览器和服务端使用同一契约。预览以文本展示材料，支持键盘操作。
2. 学习任务详情展示候选提炼和验证回执。项目写权限用于发起验证。已通过的候选可由工作区所有者创建草稿，并保留从草稿回查验证任务的链接。外部 MCP 按当前项目读权查看提炼和归一化验证回执。
3. 所有者在版本详情核对正文、验证回执及来源，提交带摘要的审核决定。发布、回滚、撤回由显式确认发出，绑定版本、审核摘要和激活序号。重复重试复用首次操作意图，冲突后重新读取状态。当前权限丢失时清除私有材料与待确认动作。
4. 使用真实浏览器、Keycloak 和 PostgreSQL 验证中英文导入、审核、发布、回滚、撤回、键盘交互及权限变化；复用 C3a 工作流核对代码规则和 Runbook 的真实来源与验证范围。

P4-D 将激活版本带入后续项目与运维任务。Runner 与下游动作继续使用现有授权闸门。
