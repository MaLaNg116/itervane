# P2-E-D3-C2 · 发布结果与外部 MCP

接续 [独立发布 Worker #58](https://github.com/MaLaNg116/itervane/pull/58)。核验结果来自 D3-B 的持久化操作、Komodo 更新及对应的核验尝试。 [发布 Worker 计划](p2-e-release-installation.md)

| 交付 | 实现与验收 |
| --- | --- |
| 同源查询 | 页面现有发布接口与只读 MCP `get_release_result` 读取同一状态。任务和项目授权覆盖每次读取，只显示当前运行的正式操作。输出限于操作和更新标识、状态、验证时间、实际镜像摘要、运行版本和脱敏原因。 |
| 双语页面 | 在现有发布面板显示排队、派发、核验中、人工核验、已验证及已阻断。确认记录继续随冻结候选展示。已验证结果依赖完成的核验事务。成功后显示当时核实的镜像和入口健康。 |
| 专项回归 | 在真实 PostgreSQL 中走一次核验成功和人工核验，对照 HTTP 与真实 MCP 客户端的结构化结果、权限撤销以及双语状态。浏览器检查状态刷新、键盘、GSAP 与减少动效偏好。 |

MCP 保留现有发布申请和候选查询契约。审批与下游执行仍由原入口和授权控制。页面遵循当前运行和任务版本，运行切换后清除旧结果。D3-D 验收同一条真实链路中的审批、部署和结果读取。
