# P4-D2b4a · 在独立复验 Runner 中重扫已发布规则

本批为正式复验增加独立的代码规则扫描回执。 [#150](https://github.com/MaLaNg116/itervane/pull/150) · [固定规则检查](p4-formal-published-inspection.md)

1. 复验输入绑定任务规则快照、审计阶段的代码扫描摘要及本次固定规则集。复验命令验证选定规则集、目标源码、镜像和租约。沿用既有 VM 与受保护的扫描通道。
2. 在一次性域内对实际交付目标重扫。原稿路径使用固定 Git 清单，修复路径使用核验后的候选清单。返回有界的清单和规则观测，调用端重新核对目标摘要、规则集、匹配范围及清理证据。
3. 验证原稿、修复候选、缺失规则证据和历史无规则请求。扩展托管场景，用独立虚拟机重扫固定样例并核对结果。后续批次把本次观测与审计回执比较，以真实目标结果决定发布资格，并使用第二个登记项目验收复用。
