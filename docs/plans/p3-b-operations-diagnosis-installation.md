# P3-B3d3 · 安装配置与原生诊断验收

接续 [双语诊断门户 #81](https://github.com/MaLaNg116/itervane/pull/81)。正式诊断使用现有受保护发布和 Whiskers 只读登记。

| 工作 | 验收 |
| --- | --- |
| 安装 | API 与 Worker 使用同一可信模型指纹。模型凭证和 Whiskers Read 密钥由 Worker 读取。配置错配阻断启动或领取。旧观察任务保留原模式。 |
| 入口 | 能力和提交入口显示当前安装支持的诊断方式。请求绑定由服务端产生。中英文门户展示同一已发布应用的相应入口。 |
| 端到端 | 在合格 Runner 建成的同一受保护容器上，由 HTTP 或 MCP 提交正式诊断，安装态 Worker 调用原生 Whiskers、完成结算并通过双语入口读回。独立记录脚本模型与实模证据。 |

原生场景核对发布证明、Whiskers 调用、诊断回执和执行槽，审核人可通过回执和事件追溯。P3-C 接续异常触发、人工处置和恢复验证。
