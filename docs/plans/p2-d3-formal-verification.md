# P2-D3 · 独立复验与镜像证据

基于 P2-D2 的正式审计、受控修复和待复验候选。按 [蓝图 v6 第 8 节](../blueprint-v6.md#8-审计修复和复验形成可验证循环)及 [TS + PostgreSQL 实施计划 P2](../implementation-plan-v2-ts-postgresql.md#p2-跑通-agent-审计修复复验和发布)，完成同一候选的干净重放、独立扫描、保护基线和针对性验证，交付 P2-E 可核对的镜像证据。开发最初以 [P2-D2 #23](https://github.com/MaLaNg116/itervane/pull/23) 的 `bcda11e` 为基线，依照 PR 依赖逐批交付。

## 准备复验

- 以当前任务代次和有效 Worker 租约领取。输入绑定仓库登记与固定提交、已核验扫描回执和源码清单、正式审计的输入/结果/检查点、规则目录及平台复验策略。相同输入可重领，修改证据或策略后需要重新准备。
- 两条入口使用同一不可变复验输入。原始分支要求完整的正式审计与扫描，原始扫描的所有强制项均无发现，保留原始清单指纹。有发现时，从同一 run 的正式修复结果获取已封存候选，重新核对精确操作、尝试回执、规范命令、补丁和候选清单指纹。模型可见的清单是有界摘要，作为分类依据的事实来自完整扫描回执。
- 候选核验复用正式补丁导出的授权后解析逻辑。平台持久化引用和必要指纹，待执行时重新核对内容。输入准备无副作用调度，审批、部署和远端状态变更继续各自依赖运行闸门。 [运行与发布边界](../decisions/0001-development-and-runtime-gates.md)

## 干净重放与受保护检查

- 每次复验重新准备一次性虚拟机。原始快照以独立的固定清单校验，修复分支在独立目录根据同一规范工作区和补丁重算候选。逐文件核对原指纹、改后指纹及候选清单，包含未修改字节、路径和原始提交关联。
- 维护者控制的复验 profile 固定扫描器、数据库和规则、平台测试包以及标准应用构建入口。目标仓库内配置不得改写平台判据和被保护路径。首次覆盖标准 React/Vite + Node.js/Express 无状态应用，实际依赖安装、测试和构建均在合格的隔离客体内完成。
- 重扫保留覆盖、扫描器版本、策略与数据库摘要。用公告与依赖坐标等稳定信息比较发现，核对目标问题退出、新增问题和剩余阻断项；源快照参与计算的发现编号用于关联原始证据。缺失扫描、保护基线变化、未运行的检查或不可比的数据库版本按不完整处理。
- 在 Runner 中使用已校验的锁文件和制品，优先利用按完整性校验的离线依赖缓存。固定构建工具、基础镜像摘要与平台构建配方。产出 OCI 镜像摘要及目标运行架构，镜像扫描和后续制品发布验证都引用同一摘要。控制面和 Agent 不接收构建机或仓库凭证。
- 运行前、心跳、产物接受和发布复验结果时复核租约、项目访问权与当前代次。取消或撤权停止新作业。只有得到确认的客体与工作区清理证据后才释放相应执行权；清理未知进入核对，不重派变更操作。

## Agent 决策与返修

独立复验角色用 ReAct 获取受保护检查与对比结果，说明证据、覆盖、变更及剩余风险。确定性服务根据同一候选的完整回执计算结果，Agent 只引用证据并给出复验说明。已有修复任务、候选和复验回执保持不可变。

有明确修复方向时返修使用新 run 和递增代次，引用上一版候选、失败项及当前授权，并用平台预算约束整体次数。缺证、权限变化、无进展、超出预算或人工选择会停止并保留状态。合格证据才供 P2-E 生成最终候选；P2-E 另负责绑定目标、配置、审批、Komodo 发布、健康和实际版本。

## 实施与验收

| 批次 | 交付 | 验收 |
| --- | --- | --- |
| D3-A | 正式复验输入和候选读取 | 确认资源与当前代次，来源是无发现原稿或同 run 已封存修复。重复准备稳定，旧租约、替换指纹及未登记输入拒绝。复用受控补丁导出的解析规则。 |
| D3-B | 合格 Runner 独立重放与复扫 | 在一次性 VM 复现候选和扫描，核对两类修复的证据、原稿路径、回归与清理；失败保留可核对状态。 |
| D3-C | 平台基线、针对性测试、构建与镜像扫描 | 在合格 VM 运行标准应用路径，核对基线摘要、测试、真实 OCI 产物和同 digest 扫描。测试失败或产物替换不能通过。 |
| D3-D | Worker、复验 Agent、返修与一致读面 | 用真实 PostgreSQL 测试事务、续领、取消与预算。用真实模型和托管 Runner 核对不同证据导致的工具选择和停止条件。门户及外部 MCP 提供双语结果和关联证据，保留现有 GSAP 行为。 |

各批单独保留固定版本、可执行验证和代码导读。P2-E、P3、P4 与 P5 继续按实施计划独立验收。
