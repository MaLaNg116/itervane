# P3-C3-D2b · 关联修复的读取、准备与确认

接续 [#131](https://github.com/MaLaNg116/itervane/pull/131)。把现有的关联修复提案和人工准入接到 HTTP 与外部 MCP，提供门户所需的双语状态。 [事件操作计划](p3-c-incident-actions.md) · [正式确认设计](p3-c-linked-repair-admission.md)

1. 授权读面返回可准备的诊断或已冻结提案，包括原发布、固定提交、是否需要固化补丁后的提交、有效期及既有任务。过期、确认和目标变化按领域证据展示。仅门户所有者看见可确认动作。
2. HTTP 与 MCP 均可按已核验诊断摘要准备提案。解析当前登记与目标后复用正式提案服务。门户确认复用原事务的授权、提交、指纹、关联和入队校验，确认可重放。外部 MCP 用相同投影查询进度。
3. 真库与真实协议验收读取角色、HTTP/MCP 双语一致性、请求重放、错误摘要、错误指纹、跨项目以及已替换发布。旧提案和已接收任务的引用继续可查。门户交互与原生停止在 C3-D3 接入。
